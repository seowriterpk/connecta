# ConectaGrupos — SQL de importación (datos demo production-ready)

**Base de datos destino:** `u824913874_connector` (MySQL/MariaDB, `utf8mb4`)

Este archivo crea **todo el esquema** (18 tablas, idéntico al Schema Guard de la app) e importa **datos demo completos y SEO-optimizados**, pensados para que Google indexe contenido único desde el primer día:

| Qué incluye | Cantidad | Detalle |
|---|---|---|
| Grupos demo | **104** | 92 limpios + 12 solo-18+ · 100% únicos (nombre, slug, descripción, tags, keywords) |
| Países hispanohablantes | **20** | México, España, Argentina, Colombia, Perú, Chile, Venezuela, Ecuador, Bolivia, Paraguay, Uruguay, Cuba, Costa Rica, Guatemala, Honduras, El Salvador, Nicaragua, Panamá, Rep. Dominicana, Puerto Rico |
| Categorías | **22** | 20 limpias + 2 solo-18+ (`citas-18`, `contenido-exclusivo-18`) · cada una con 4–7 grupos (nada de páginas delgadas) |
| Curadores (autores) | **6** | Perfiles completos visibles en `/autor/...` |
| Valoraciones | **76** | Consistentes con `avgRating`/`ratingCount` de cada grupo |
| Artículos de blog | **2** | Publicados, con metadatos SEO y enlaces internos |

**Decisiones anti-contenido-genérico** (lo que Google penaliza y aquí se evita):
- Cada grupo tiene **nombre, descripción (2–3 frases), slug, tags y keywords escritos a mano** — cero plantillas repetidas.
- Cada tag aparece en **≥ 2 grupos** → ninguna página `/etiqueta/...` queda con un solo resultado.
- Cada categoría tiene **≥ 4 grupos** y cada país **≥ 2** → ninguna página de categoría/país delgada.
- `createdAt`, `lastActiveAt` y `lastValidatedAt` son **relativos a la fecha de importación** (`UTC_TIMESTAMP() - INTERVAL n DAY`) → las secciones *Nuevos* y *Populares* siempre muestran actividad fresca.
- Métricas **correlacionadas y realistas** (views > clicks > joins > shares), no números aleatorios gigantes.
- Los grupos 18+ **solo** viven en categorías 18+ (`isAdult=1`): el silo adulto queda aislado del contenido limpio, con `noindex` + etiqueta RTA gestionados por la app.

## Cómo ejecutarlo

**Opción A — phpMyAdmin (hPanel de Hostinger):**
1. Entra a phpMyAdmin y selecciona la base `u824913874_connector` (ya creada desde hPanel).
2. Pestaña **Importar** → pega el SQL de abajo (o súbelo como archivo) → *Continuar*.
3. Si tu panel rechaza la línea `USE`, elimínala: con la base ya seleccionada no hace falta.

**Opción B — SSH (CLI):**
```bash
mysql -u u824913874_connector -p u824913874_connector < sql.sql
```

**Cuándo:** da igual si lo haces **antes o después** del primer arranque de la app — el SQL usa `CREATE TABLE IF NOT EXISTS` e `INSERT ... ON DUPLICATE KEY UPDATE`, así que es **idempotente** y se puede re-ejecutar sin duplicar nada.

## Después de importar

1. **Reemplaza los enlaces de invitación demo** (`https://chat.whatsapp.com/…`) por enlaces reales de tus grupos desde **/admin** (el validador de enlaces marcará los demo como revocados en su siguiente pasada — es el comportamiento esperado).
2. Regenera sitemaps + RSS para incluir los datos nuevos:
   ```bash
   node scripts/crons/sitemap-generator.mjs
   ```
3. Verifica con las consultas del final del SQL (sección 8).
